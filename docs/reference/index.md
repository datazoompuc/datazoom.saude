# Package index

## Mortality (SIM)

Mortality Information System: general, fetal, infant, maternal and
external-cause deaths.

- [`load_mortality()`](https://datazoom.com.br/datazoom.saude/reference/load_mortality.md)
  : Load Brazilian mortality data from the SIM system via DATASUS

## Live births (SINASC)

Live Birth Information System.

- [`load_births()`](https://datazoom.com.br/datazoom.saude/reference/load_births.md)
  : Loads birth data of newborns from Brazil provided by DATASUS

## Hospital admissions (SIH)

Hospital Information System of SUS: AIH records, professional services
and rejected AIHs.

- [`load_hospital_admissions()`](https://datazoom.com.br/datazoom.saude/reference/load_hospital_admissions.md)
  : Loads hospital admission data from Brazil provided by DATASUS
  (SIHSUS)

## Outpatient procedures (SIA)

Outpatient Information System of SUS: ambulatory production and APAC
sub-datasets.

- [`load_outpatient_procedures()`](https://datazoom.com.br/datazoom.saude/reference/load_outpatient_procedures.md)
  : Loads outpatient procedure data from Brazil provided by 'SIASUS'
  (Ambulatory Information System)

## Hospital beds (CNES)

Monthly hospital beds from the National Registry of Health
Establishments (CNES-LT).

- [`load_hospital_beds()`](https://datazoom.com.br/datazoom.saude/reference/load_hospital_beds.md)
  : Load monthly data on hospital beds from Brazil's National Health
  Facilities Registry

## Oncology cases (PO)

Oncology Panel (PAINEL-Oncologia).

- [`load_oncology_case()`](https://datazoom.com.br/datazoom.saude/reference/load_oncology_case.md)
  : Loads oncology case data from Brazil provided by DATASUS

## Vaccination (SI-PNI)

National Immunization Program Information System.

- [`load_vaccines()`](https://datazoom.com.br/datazoom.saude/reference/load_vaccines.md)
  : Load Brazilian vaccination data from the SI-PNI system via DATASUS

## Utilities

Helpers for DATASUS file formats and package documentation.

- [`dbc2dbf_wrapper()`](https://datazoom.com.br/datazoom.saude/reference/dbc2dbf_wrapper.md)
  : Decompress a DBC (compressed DBF) file
- [`datazoom.saude`](https://datazoom.com.br/datazoom.saude/reference/datazoom.saude-package.md)
  [`datazoom.saude-package`](https://datazoom.com.br/datazoom.saude/reference/datazoom.saude-package.md)
  : datazoom.saude: Download Brazilian Health Data from DATASUS
